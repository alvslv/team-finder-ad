# TeamFinder

## О проекте

TeamFinder — это веб-приложение для поиска единомышленников и совместной работы над pet-проектами. Платформа позволяет разработчикам, дизайнерам и другим специалистам публиковать идеи проектов, находить команду и откликаться на предложения.

### Основные возможности

- Регистрация и аутентификация пользователей (вход по email)
- Создание, редактирование и завершение проектов
- Добавление проектов в избранное
- Фильтрация пользователей по различным критериям
- Присоединение к проектам
- Личный кабинет с возможностью редактирования профиля
- Смена пароля

## Технологический стек

- Python 3.11
- Django 5.2
- PostgreSQL
- Docker / Docker Compose

## Установка и запуск

### 1. Клонирование репозитория

`git clone https://github.com/alvslv/team-finder-ad.git`
`cd team-finder-ad`

### 2. Создание и активация виртуального окружения

`python3 -m venv venv`
`source venv/bin/activate`

### 3. Установка зависимостей

`pip install -r requirements.txt`

### 4. Настройка переменных окружения

`cp .env_example .env`

Отредактируйте файл `.env`, укажите свои значения.

### 5. Запуск базы данных через Docker

`docker compose up -d`

### 6. Выполнение миграций

`python manage.py makemigrations`
`python manage.py migrate`

### 7. Создание суперпользователя

`python manage.py createsuperuser`

### 8. Запуск сервера разработки

`python manage.py runserver`

### 9. Доступ к сайту

- Главная страница: http://127.0.0.1:8000/projects/list/
- Админ-панель: http://127.0.0.1:8000/admin/

## Структура проекта

- core/ - общие модули (константы, валидаторы, утилиты)
- users/ - приложение пользователей
- projects/ - приложение проектов
- team_finder/ - настройки проекта
- templates_var1/ - HTML-шаблоны
- static/ - статические файлы
- media/ - пользовательские файлы
